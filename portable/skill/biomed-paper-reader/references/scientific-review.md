# 科学审查规则

按读出建立账本，避免将相关现象压成单一“机制强度”。

| 读出 | 可以说 | 不能单独说 |
|---|---|---|
| 图像凝聚面积/形态 | 给定条件下的面积比例、形状与分布 | 蛋白质量分数、平衡相图或液态确证 |
| 荧光富集/共定位 | 指定ROI和标记条件下的空间分配 | 校准浓度、直接结合常数或交换速率 |
| FRAP | 指定漂白、观测时间和归一化下的恢复 | 唯一黏度、扩散系数、LLPS证明；未给模型不得反演参数 |
| rRNA qPCR | 相对内参的RNA稳态丰度 | 单独的转录速率、核糖体装配率 |
| puromycin | 给定脉冲的标记掺入与新生翻译相关读出 | 仅由核仁导致的效应或成熟核糖体计数 |
| ATP发光活力 | ATP相关活力信号 | 直接细胞计数、凋亡机制或临床疗效 |

处理同图多实验时逐一核对：全长/肽、荧光探针、浓度、模型组分、细胞背景、时序、归一化、样本单位。视野/液滴/细胞不能冒充独立生物重复。正文、图注、Reporting Summary 的冲突分别保留，不自行裁定。

救援实验具有解释力，但删除片段可能同时改变表达、结合、构象和动力学。写成作者支持的机制模型，并列可替代解释。NS是不显著，不是已证明等效。曲线趋势没有检验时不能自行称统计显著。

生物物理三级背景可以解释可观测量和模型假设，但不得把教学公式写成本文拟合。转化讨论明确模型层级及未测的患者/组织/治疗问题。外部背景引用实际查阅的原始文献，并标记读取摘要或全文的范围。

审查记录必须包含读过的具体PDF页/panel、发现的问题、修复及剩余问题。区分资产完整性、转述准确性、因果强度和数据复算四种检查。
